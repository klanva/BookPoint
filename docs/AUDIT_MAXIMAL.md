## Часть 1. Текущее состояние BookPoint (что уже есть)

Ядро: EPUB/TXT/XTC/XTC-2GB, сноски внизу страницы (универсальный экстрактор,
host-тест на реальных книгах), статистика (сессии/время/страницы/темп/остаток/

импорт inkMOD), часы X4 (NTP + восстановление после сна, По центру/Слева/Справа),
строка состояния (Верх/Низ/Скрыть, подменю, номера страниц по книге), быстрое
листание с очередью нажатий и пропуском промежуточных e-ink кадров, сетка
статистики 3x2, dashboard-тема со статистикой на главном, Minimal-тема («4
плитки»), Dashboard-тема, темы Classic/Lyra/Lyra3Covers/RoundedRaff, прогноз
даты финиша, серия дней, клиппинги (My Clippings.txt), диагностика железа,
словари по Wi-Fi (RU-EN/EN-RU WikDict) + StarDict + .syn, OPDS + автокаталоги,
KOReader sync, Calibre, USB Drive (X4 Pro, MSC), Quick Lock, лог батареи,
автовыключение Wi-Fi, минимальные поля 0, документация на русском.

## Часть 5. Приоритизированный бэклог (то, чего реально ещё нет)

### Уровень 1 — дёшево и ценно
1. **Адаптивные сноски** (шаг 3 из Antigravity): полоса по высоте контента,
   автоуменьшение шрифта длинных примечаний, лимит 40% экрана.
2. **Sunlight Fading Fix** (inkMOD) — фикс выцветания белых X4 на солнце, мало кода.
3. **Автодетект кодировок TXT** (InkPointX): CP1251/KOI8-R/CP866 — русские легаси-тексты.
4. **Markdown-ридер** (Inx) — поверх TXT-движка.
5. **Экран сна Date/Time + Календарь** (Inx, inkMOD) — часы/календарь как заставка.
6. **Правка статистики** (vCodex): ±время, дата старта, сброс per-book; показ
   времени с последней зарядки в диагностике (данные уже пишутся).
7. **Блок «Диагностика системы»** в настройках (шаг 4 из Antigravity).

### Уровень 2 — средне
8. **Highlights с текстовыми якорями** (vCodex) — выделения переживают смену шрифта.
9. **Heatmap + Achievements + Goals** (vCodex) — геймификация поверх готовой статистики.
10. **Экраны сна со статистикой** (Cover+Stats, Minimal Stats) — статы на заставке.
11. **Flashcards SM-2** (vCodex/CrossPet) — офлайн-карточки, CSV-импорт.
12. **KOReader-профили + auto-pull/push** (vCodex).
13. **Hold-to-repeat в меню/списках** (inkMOD) + «Закончить книгу» из меню (CrossInk).
14. **Стрейк-напоминания/серия на сне** (см. #10).

### Уровень 3 — большие/нишевые
15. **PDF-ридер с зумом** (InkPointX) — уникально, но тяжело.
16. **Dark mode UI** + Text Darkness (vCodex).
17. **Dual font model** (CrossPet) — основной + дополнительный шрифт.
18. **Karakeep / TRMNL** (CrossInk-TRMNL) — веб-сервисы, по желанию.
19. **Virtual Pet / Pomodoro** (CrossPet) — геймификация/утилита.
20. **EPUBKIT-браузер + генераторы сна/шрифтов** (inkMOD) — веб-инструменты.

### Не делать
- FB2 в любом виде (решение зафиксировано).
- BLE-клавиатура, BLE-синк статистики (батарея).
- Игры (шахматы/сапёр/2048) — вес и отвлечение от задач читалки.
- SUMI (меняет таблицу разделов — риск на залоченных устройствах).
- Pentest-набор biscuit.

## Часть 6. Технические долги и ловушки

- PlatformIO на Windows копирует symlink-библиотеки в .pio/libdeps: после
  обновления freeink-sdk чистить .pio/libdeps/default, иначе сборка идёт по
  старой копии (ловилось на SDCardManager::shutdown).
- Ветка и тег пушить раздельно; push --tags тащит мусорные теги апстрима.
- Версия в platformio.ini ([crosspoint] version) должна совпадать с номером
  релиза — проверять перед каждым релизом.
- Возврат X4 Pro env (удалены по запросу) вернёт и USB Drive на X4 Pro —
  код сохранён в истории (коммит 6529d41).
- Незакрытый предпросмотр строки состояния в настройках не учитывает «Верх»
  (косметика, отложено).
