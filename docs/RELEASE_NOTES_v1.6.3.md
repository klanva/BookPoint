Микропрограмма BookPoint версии 1.6.3 для электронных книг первого поколения (ESP32-C3).

## Основные изменения

### Режим чтения и парсер сносок
- **Универсальный экстрактор якорей**: обеспечен поиск элементов сносок по атрибутам `id`, `xml:id` и `name` без учета регистра и лишних пробелов, включая файлы отдельных примечаний и блочные div-структуры.
- **Фильтрация паразитного текста**: служебные фразы обратного перехода («Назад», «Вернуться») автоматически вырезаются из текста сноски.
- **Настройка книжных полей**: минимальный размер боковых полей страницы уменьшен с 5 до 0 пикселей для максимального заполнения экрана текстом.

### Графический интерфейс и статистика
- **Новая верстка дашборда статистики**: интегрирован крупный графический индикатор прогресса, двухколоночная сетка ключевых метрик с полужирным начертанием и визуальные разделители между смысловыми блоками.
- **Оптимизация структуры главного меню**: пункт статистики перенесен в меню книги и настройки, предотвращая смещение пункта «Настройки» за пределы видимости на альтернативных темах оформления.

### Системные часы и сервисы
- **Стандартизация часов в строке состояния**: пункт включения часов доступен постоянно, время корректно инициализируется после первой синхронизации по NTP.

## Установка и обновление

### Файл прошивки
- `BookPoint_1.6.3_xteink_x4_x3.bin` — бинарный образ микропрограммы для **Xteink X4 и X3** (ESP32-C3).

### Способы установки
1. **Через веб-программатор (WebSerial)**:
   - Открыть страницу https://crosspointreader.com/#flash-tools в браузере с поддержкой WebSerial (Chrome / Edge).
   - Подключить устройство кабелем USB к компьютеру, выбрать файл `BookPoint_1.6.3_xteink_x4_x3.bin` и нажать **Install**.
2. **С карты microSD**:
   - Скопировать файл `BookPoint_1.6.3_xteink_x4_x3.bin` в корневую директорию карты памяти microSD и переименовать его в `update.bin`.
   - Вставить карту в ридер и подтвердить обновление в системных настройках.
