# Шрифты с SD-карты

Помимо двух встроенных (Noto Serif, Noto Sans) можно ставить свои шрифты,
в том числе с CJK, греческим, ивритом и другими символами.

## Установка

### Способ 1: скачать с устройства (проще всего)

1. Подключите ридер к Wi-Fi.
2. Настройки, Система, Управление шрифтами.
3. Выберите семейство из списка, оно скачается и сразу появится в
   Настройки, Чтение, Шрифт.

### Способ 2: через браузер

1. Передача файлов, подключитесь к сети или создайте точку доступа.
2. Откройте адрес ридера в браузере, вкладка Шрифты.
3. Загрузите файлы `.cpfont` (можно конвертировать TTF/OTF прямо в
   браузере).

### Способ 3: вручную на SD-карту

1. Скачайте готовые шрифты из репозитория
   [crosspoint-fonts](https://github.com/crosspoint-reader/crosspoint-fonts).
2. Скопируйте папки семейств на SD-карту в `/.fonts/` (скрытая папка,
   предпочтительно) или `/fonts/` (видимая). Обе папки сканируются и
   объединяются. Если одно семейство лежит в обеих, побеждает `/.fonts/`.

       SD/
       ├── .fonts/
       │   └── Literata/
       │       ├── Literata_12.cpfont
       │       ├── Literata_14.cpfont
       │       ├── Literata_16.cpfont
       │       └── Literata_18.cpfont
       └── fonts/
           └── Merriweather/
               ├── Merriweather_12.cpfont
               └── ...

## CJK в интерфейсе

Встроенные шрифты интерфейса содержат только латиницу и кириллицу.
Названия книг и файлы с иероглифами без дополнительного шрифта показываются
квадратиками. Большой CJK-набор в прошивку не зашивают, вместо этого
интерфейс использует выбранный вами SD-шрифт: строка с иероглифами
рисуется вашим шрифтом подходящего размера.

Чтобы это работало, в семействе должны быть размеры 8, 10 и 12 (помимо
читательских 12-18). Если выбрать CJK-шрифт в качестве шрифта чтения,
иероглифы появятся и в интерфейсе, и в книгах.

## Свои шрифты: конвертация

Нужен Python и `pip install freetype-py fonttools`.

Один стиль:

    python3 lib/EpdFont/scripts/fontconvert_sdcard.py \
      MyFont-Regular.ttf \
      --intervals latin-ext \
      --sizes 12,14,16,18 \
      --style regular \
      --name MyFont \
      --output-dir ./MyFont/

Несколько начертаний:

    python3 lib/EpdFont/scripts/fontconvert_sdcard.py \
      --regular MyFont-Regular.ttf \
      --bold MyFont-Bold.ttf \
      --italic MyFont-Italic.ttf \
      --bolditalic MyFont-BoldItalic.ttf \
      --intervals latin-ext,cyrillic \
      --sizes 12,14,16,18 \
      --name MyFont \
      --output-dir ./MyFont/

Наборы символов (`--intervals`, можно через запятую):

| Набор | Покрытие |
|-------|----------|
| `ascii` | базовая латиница |
| `latin-ext` | европейские языки |
| `cyrillic` | кириллица |
| `greek` | греческий |
| `hebrew` | иврит |
| `cjk` | китайский, японский |
| `hangul` | корейский |
| `ipa-chars` | фонетическая транскрипция |
| `symbols` | математика, стрелки, символы |
| `reading` | художественная литература: латиница, греческий, кириллица, символы |

Полный список: `--list-presets`. Можно задавать свои диапазоны:
`--intervals latin-ext,(0x2100-0x214F)`.

Список готовых шрифтов: [crosspoint-fonts](https://github.com/crosspoint-reader/crosspoint-fonts).
