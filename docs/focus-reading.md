# Focus Reading

Режим чтения, при котором начало каждого слова выделяется жирным. Взгляд
цепляется за эти точки, читать становится проще, глаза меньше разбегаются.
Идея взята из методики Bionic Reading. Включается в Настройки, Чтение,
Focus Reading, по умолчанию выключен.

<img src="./images/focus-reading/focus-reading.jpg" height="500" alt="Страница с включенным и выключенным Focus Reading" />

Слева выключено, справа включено.

## Заметки

- Действует только на обычный текст, заголовки и курсив не трогаются.
- Настройка общая для всех книг, не на отдельную книгу.
- Включение перестраивает кэш глав, как смена шрифта, страницы
  пересобираются по мере чтения. Сами файлы EPUB не изменяются.
