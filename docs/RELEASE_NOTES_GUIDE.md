# Стандарт оформления релизов BookPoint OS (Release Notes Styleguide)

Данный документ является обязательным стандартом для формирования описаний релизов, тегов и сопроводительной документации в проекте BookPoint OS.

---

## 1. Анатомия ошибок: почему релиз v2.2.1 со скриншота выглядел плохо

1. **Дублирование заголовка первого уровня**:
   - *Ошибка*: Написание `# BookPoint OS vX.Y.Z ...` первой строкой в Markdown-теле релиза при том, что поле Title релиза на GitHub уже заполнено этим же текстом.
   - *Следствие*: В веб-интерфейсе GitHub пользователь видит огромный заголовок дважды подряд один под другим.
2. **Перегруженное имя релиза**:
   - *Ошибка*: Заголовок вида `BookPoint OS v2.2.1 — Flawless Hardware BM8563 RTC Local Timekeeping`.
   - *Канон*: Заголовок должен быть лаконичным и строгим: `BookPoint v2.2.1`.
3. **Визуальный шум и эмодзи-спам**:
   - *Ошибка*: Использование разномастных значков (`🇷🇺`, `🇬🇧`, `🔍`, `⚙️`, `🧪`), превращающих инженерный релиз в телеграм-пост.
   - *Канон*: Чистый, строгий Markdown. Допустимо минимальное выделение, но текст должен читаться как профессиональная документация (стиль Linux kernel, Kobo, Kindle, PostmarketOS).
4. **Отсутствие инструкций по установке**:
   - *Ошибка*: Выкатить бинарник с сухим списком коммитов, не указав, как рядовому пользователю поставить прошивку на ридер.
   - *Канон*: Обязательный блок «Установка и обновление» с тремя стандартными путями (WebSerial, microSD, OTA).

## 2. Золотой канон оформления релиза (Шаблон)

```markdown
Микропрограмма BookPoint версии X.Y.Z для электронных книг Xteink X4 Pro (ESP32-S3).

## Основные изменения

### [Тематическая категория 1: например, Интерфейс и навигация]
- **Ключевая функция**: четкое описание пользовательской пользы или исправленного дефекта. Без эмоциональных отступлений и без роботизированных скобок.
- **Вторая функция**: описание изменений в поведении системы.

### [Тематическая категория 2: например, Аппаратная интеграция и ядро]
- **Драйвер или подсистема**: технически точное описание аппаратных правок (чипы, шины, тайминги, энергопотребление).

## Установка и обновление

### Файл прошивки
- `BookPoint_X.Y.Z_x4pro.bin` — бинарный образ микропрограммы для **Xteink X4 Pro** (ESP32-S3).

### Способы установки
1. **Через веб-программатор**:
   - Открыть страницу https://crosspointreader.com/#flash-tools в браузере с поддержкой WebSerial (Chrome / Edge).
   - Подключить ридер кабелем по USB, выбрать файл `BookPoint_X.Y.Z_x4pro.bin` и нажать **Install**.
2. **С карты microSD**:
   - Скопировать файл `BookPoint_X.Y.Z_x4pro.bin` в корень карты памяти под именем `update.bin`.
   - Запустить пункт обновления в системных настройках устройства.
3. **Беспроводное обновление (OTA)**:
   - В меню «Система» выбрать «Проверить обновления» при активном подключении к Wi-Fi.
```

## 3. Чеклист перед публикацией релиза

- [ ] В заголовке релиза на GitHub указано строго: `BookPoint vX.Y.Z`.
- [ ] В первой строке Markdown-тела **НЕТ** заголовка `# ...`. Начинается сразу с аннотации.
- [ ] Все изменения сгруппированы по разделам с подзаголовками `###`.
- [ ] Каждый пункт начинается с жирного термина: `- **Компонент**: описание.`
- [ ] Присутствует секция `## Установка и обновление` с тремя способами прошивки.
- [ ] Имя бинарного файла соответствует соглашению: `BookPoint_X.Y.Z_x4pro.bin`.
- [ ] Бинарник собран начисто (`pio run -e x4pro`), проверен через `esptool image-info` и прикреплен к релизу.
