# Словари

Поиск слов во время чтения EPUB через офлайн-словари StarDict с SD-карты.

## Формат

Поддерживаются словари **StarDict**. Папка словаря должна содержать:

- `.idx` — индекс слов (обязательно, **несжатый**; `.idx.gz` не работает,
  распакуйте на компьютере через `gzip -d`)
- `.dict` или `.dict.dz` — статьи (`.dict.dz` поддерживается как есть)
- `.syn` — синонимы (необязательно)
- `.ifo` — метаданные (необязательно)

Не поддерживаются словари с 64-битными смещениями (`idxoffsetbits=64`
в `.ifo`, встречается редко).

## Настройка

1. Скопируйте папки словарей в `/dictionaries/` на SD-карте, один словарь
   в одной папке. Скрытая `/.dictionaries/` тоже работает.
2. Настройки, Чтение, Словарь.
3. Выберите словарь из списка. Пункт появляется только если найден хотя
   бы один словарь.

## Поиск слова

Два способа: меню книги, «Словарь», или назначить долгое нажатие Confirm
на словарь в настройках кнопок и держать Confirm на странице.

Одно слово на странице подсвечивается:

1. Left/Right — переход между словами, боковые Up/Down — между строками.
2. Confirm — показать статью.
3. Back — вернуться к выбору.

При первом использовании словарь индексируется несколько секунд, дальше
поиск мгновенный.

Порядок поиска: прямое совпадение без учета регистра, затем синонимы из
`.syn`, затем автоматические формы слова (окончания, множественное
число). Не нашлось — короткое уведомление.

## Где брать словари

- https://www.reader-dict.com — словари Wiktionary на многие языки
- https://www.wikdict.com — двуязычные словари, есть русско-английские
- https://download.wikdict.com/dictionaries/stardict/ — прямые ссылки
- https://xxyzz.github.io/wiktionary_stardict/ — обновляются ежемесячно
