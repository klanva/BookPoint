Пользователь (GitHub **klanva**) владеет Xteink X4 (разлоченный, куплен не у официалов). Мод называется **BookPoint** — форк CrossPoint Reader (база 1.6.0 beta RC03, тег `1.6.0rc`).

**Канонический репозиторий:** `C:\xteinkx4\src`, ветка `bookpoint-main`, опубликован на https://github.com/klanva/BookPoint. **Нумерация версий привязана к CrossPoint** (требование пользователя): релизы `v1.6.0`, `v1.6.1`, `v1.6.2` (дальше 1.6.3...), на устройстве видно `1.6.x-bookpoint` (через scripts/git_branch.py, base version в platformio.ini). Готовый бин: `.pio\build\default\firmware.bin`; копия в workspace-папке.

**Сборка:** `cd C:\xteinkx4\src && cmd //c build.bat` (env `default` = X4+X3 ESP32-C3). Ловушки:
- Путь без пробелов (ESP-IDF падает на "whitespace in project paths"); workspace-папка с пробелом не переименовывается (держится открытым шеллом) — рабочая копия только в C:\xteinkx4.
- Git Bash ломает сборку («MSys/Mingw is not supported») — build.bat чистит MSYSTEM и Git-пути в PATH; robocopy из bash искажает флаги (использовать cp -a).
- freeink-sdk — сабмодуль: `git submodule update --init --depth 1`.
- Пайп `pio run | tail` маскирует код ошибки — писать PIO_EXIT в файл.
- gen_i18n.py: YAML без комментариев; любой STR_* из кода обязан быть в english.yaml.
- Bare-инклуды из поддиректорий не резолвятся: писать src-root-относительно (`activities/settings/X.h`), HttpDownloader = `network/HttpDownloader.h`.
- **Не писать C++ через python-хередоки в bash** — экранирование (`\t`, `\n`, char-литералы) ломается и файл приходится переписывать целиком через Write. Проверено дважды на FootnoteTextExtractor.cpp.
- `git push --tags` тащит все локальные теги апстрима: теги апстрима удалены локально и на origin, новые теги пушить точечно (`git push origin refs/tags/v1.6.2`).
- Токен из `git credential fill` (работает для push/релизов/ассетов) **не имеет прав admin** — описание и topics репо через API не меняются, текст описания выдаётся пользователю для ручной вставки.
- Релизы: PATCH существующего релиза меняет tag_name/имя ассета, ассеты грузятся через uploads.github.com.

**Что уже в моде (v1.6.4):** статистика чтения (свой движок src/stats/, `/.crosspoint/stats/` вне кэша книг, авто-CSV-снапшот, импорт из inkMOD, экран ReadingStatsActivity — редизайн: прогресс-бар, двухколоночная сетка жирным, график 14 дней); сноски «внизу страницы» (FootnoteTextExtractor: захват всего элемента с якорем id/xml:id/name без учета регистра/пробелов, отсечение ведущего номера по лейблу, вырезание текста back-ссылок «Вернуться»/href с back + хвостовые слова; разделитель полосы не рисуется без текста; **полоса очищается fillRect на каждой странице** — partial refresh оставлял призраки на страницах без сносок; проверено на royallib `<span id="id17"><div>14</div><p>текст</p></span>` и ЛитРес `<div id="note1">…<a href="...#back_note1">`); возврат из сноски по Power даже при режиме «Power = листание»; часы X4 — **в drawStatusBar тоже был гейт isAvailable, убран**; вариант «По центру» (STATUS_BAR_CLOCK_CENTER добавлен В КОНЕЦ enum — хранимые индексы не сдвигать); до первого NTP часы пустые, юзеру говорить подключить Wi-Fi один раз; строка состояния EPUB/TXT: statusBarPosition (Низ/Верх) + statusBarHidden (скрыть целиком, марджины отдаются тексту), BaseTheme::drawStatusBar единственная (темы не переопределяют); автовыключение Wi-Fi (3 мин); лог батареи; OPDS-каталоги **при каждом запуске**; скачивалка словарей WikDict RU-EN/EN-RU; минимальные поля 0; размеры шрифта пер-фамильные: Noto Sans {8,12,14,16,18} (8pt = уже зашитый smallFont, SMALL_FONT_ID), Noto Serif {12,14,16,18}; размеры 10-24 только через SD-шрифты (.cpfont, конвертация в браузере позволяет любые размеры); документация на русском. Нюанс v1.6.4 (отложенный косметический фикс): живой предпросмотр в окне «Настройка строки состояния» всегда рисуется снизу, независимо от «Положение строки: Верх» — на реальной странице чтения позиция применяется верно; предложил пользователю подправить предпросмотр позже.

**Отменено/выучено:** пункт «Статистика чтения» на главном экране УДАЛЁН в v1.6.3 — выталкивал «Настройки» за пределы экрана; FB2-конвертер (Fb2Convert, FB2→EPUB на устройстве) — начал делать, пользователь отменил полностью, файлы удалены. Версия в platformio.ini [crosspoint] version обязана совпадать с номером релиза (заметил рассинхрон v1.6.2/на устройстве 1.6.1).

**Батарея — жёсткий приоритет пользователя** (за ночь уходило 6%): любые добавления не должны иметь фоновых задач/таймеров/радио; Wi-Fi гасить как можно раньше.

**Принцип пользователя:** не копировать inkMOD, а делать своё и заметно лучше (inkMOD по его словам лагучий и мерцает). Форматирование текстов (заголовки, болд) — оставлять, эмодзи — убирать.

**Ждёт реакции пользователя:** тест v1.6.4 (часы «По центру» после разового подключения Wi-Fi, «Положение строки: Верх», «Скрыть строку состояния», сноски без призраков, размер 8 у Noto Sans), battery_log.csv для диагностики ночного расхода. Возможные следующие шаги: in-book search, статистика для TXT/XTC, правка дат в статистике, предпросмотр строки состояния с учетом «Верха». Пользователю выдан текст описания репо и topics для ручной вставки (окно Edit repository details). README.md на главной обновлен под v1.6.4 (строка состояния, словари, размеры шрифтов, версии идут за CrossPoint) — коммит 9048b01.

## 2. Стиль общения и правила пользователя (writing-style-no-ai-flavor.md)

---
name: writing-style-no-ai-flavor
description: Писать по-человечески без эмодзи и ИИ-оборотов, но форматирование
  (заголовки/болд) оставлять
metadata:
  node_type: memory
  type: feedback
  originSessionId: sess_c55a845f-973b-4a3e-9ec9-fcc661a6c61d
---

Пользователь дважды корректировал стиль. Сначала: тексты звучат «прям как нейронка», эмодзи — кринж, длинные тире убрать. Потом уточнил: «форматирование у тебя прекрасное было вообще его оставь, ну эти большие жирные и прочее» — то есть rich-форматирование (заголовки, болд, структура списков) сохранять, убирать только эмодзи.

**Why:** эмодзи и ИИ-интонация раздражают, но выхолащивание форматирования тоже не нужно — красивая структура в README и релизах ценится.

**How to apply:** README, релизы, коммиты, ответы — живой русский без эмодзи, без длинных тире вместо обычной пунктуации, с нормальными заголовками и выделением ключевого. Образец: README и описания релизов https://github.com/klanva/BookPoint. Также пользователь просил «для обычного юзера без мороки» — решения формулировать и реализовывать так, чтобы работали сразу и без ручных танцев.
