# BookPoint

Прошивка для ридеров **Xteink X4 / X3** — расширенная версия
[CrossPoint Reader](https://github.com/crosspoint-reader/crosspoint-reader)
(v1.6.0 beta RC03) с фокусом на статистику чтения, удобные сноски и время
автономной работы.

> Firmware for Xteink X4/X3 e-readers: a feature extension of CrossPoint
> Reader focused on reading statistics, paper-style footnotes and battery
> life. (English summary below.)

## Что добавлено / What's new

### 📊 Статистика чтения
- Время чтения считается по страницам с отсечкой простоя (5 минут), темп
  «сек/страница» и **оценка времени до конца книги**.
- Экран статистики: книга / устройство / активность — **график за 14 дней**
  (реальные секунды по дням), распределение по дням недели и времени суток,
  серии дней (стримы), отметка «прочитано».
- Всё хранится на SD-карте в `/.crosspoint/stats/` — **вне кэша книг**:
  переживает обновление прошивки, смену шрифта и «Очистить кэш».
- Атомарная запись + `.bak`-бэкап + защита от записи поверх нового формата.
- **CSV-снапшот** (`/.crosspoint/stats/reading_stats.csv`) переписывается
  после каждой сессии — данные не теряются даже при замене прошивки.
- **Импорт из inkMOD** (глобальная статистика и по книгам) — однократно,
  при первом запуске.

### 📖 Сноски
- Режим **«Внизу страницы»** (по умолчанию): текст сноски печатается мелким
  шрифтом под разделителем внизу страницы, как в бумаге. Работает и когда
  примечания лежат в отдельном файле в конце EPUB. Пагинация не «прыгает»:
  место под полосу резервируется детерминированно.
- Режим **«Переход с возвратом»**: прыжок к сноске; назад — короткий Back
  или Power.
- Прогресс при чтении сноски «прибит» к исходной странице: сон/сбой не
  оставит вас в конце книги, а **KOReader-синхронизация никогда не отправит
  позицию сноски** на сервер.

### 🔋 Автономность
- **Автовыключение Wi-Fi** по бездействию (по умолчанию 3 минуты, настройка
  0–30): экраны передачи файлов и OPDS сами гасят радио. Wi-Fi — самый
  крупный потребитель батареи (~50–100 мА).
- Часы работают и на X4 (без RTC-чипа): системное время + NTP при
  подключении Wi-Fi, восстановление после глубокого сна. Нулевой расход.
- Опциональный **лог батареи** (`/.crosspoint/battery_log.csv`): строки
  boot/sleep с процентами — для диагностики ночного расхода.

### 📚 Прочее
- OPDS-каталоги по умолчанию: Flibusta (+ зеркало) и Project Gutenberg.

## Установка / Install

Прошивается как обычный CrossPoint: через веб-флешер по USB
(https://flash.crosspointreader.com) или файлом с SD-карты.
Готовые сборки — в [Releases](../../releases).

Настройки, книги, прогресс и накопленная статистика совместимы с
CrossPoint 1.6.0 и переносятся автоматически.

⚠️ **Не обновляйтесь через встроенный OTA** («Проверить обновления») — он
установит оригинальный CrossPoint поверх BookPoint.

## Сборка / Build

```bash
git clone --recurse-submodules https://github.com/klanva/BookPoint.git
cd BookPoint
# Windows: путь к проекту БЕЗ ПРОБЕЛОВ (требование ESP-IDF)
build.bat          # = pio run -e default (X4 + X3, ESP32-C3)
# результат: .pio/build/default/firmware.bin
```
