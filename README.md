# BookPoint

Прошивка для **Xteink X4 Pro** (ESP32-S3, 16 МБ флеш, 8 МБ PSRAM, USB-OTG).

BookPoint начинался как мод CrossPoint Reader и вырос в самостоятельную прошивку
со своим характером: акцент на автономность, мгновенный отклик, статистику чтения
и удобные сноски. Интерфейс и инженерные решения собираются из лучших практик
всей экосистемы прошивок Xteink (прорецензировано 18 форков, выводы в
docs/AUDIT_MAXIMAL.md и firmwares/*/AUDIT.md).

## Поддерживаемое железо

| Устройство | Поддержка | Примечание |
|---|---|---|
| **Xteink X4 Pro** (ESP32-S3) | основная цель | USB Drive, PSRAM-фреймбуфер |
| Xteink X4 / X3 (ESP32-C3) | унаследовано | env default/gh_release; USB Drive недоступен аппаратно |

## Возможности

### Чтение
- EPUB 2/3, TXT, XTC/XTCH; встроенные стили книги; переносы; CJK+RTL
- Сноски внизу страницы: текст примечания печатается под разделителем на той же
  странице, как в бумажной книге; универсальный экстрактор (royallib, ЛитРес,
  отдельные файлы примечаний), проверен автотестом на реальных книгах
- Быстрое листание: очередь нажатий, пропуск промежуточных e-ink кадров
- Статистика чтения: время, сессии, страницы, темп, остаток, серия дней, график
  за 14 дней, утро/день/вечер/ночь, CSV-снапшот после каждой сессии, импорт из
  предыдущих версий прошивок; сетка 3x2 и dashboard на главном экране
- Клиппинги с экспортом в My Clippings.txt
- Словари StarDict; RU-EN и EN-RU скачиваются по Wi-Fi прямо с устройства
- Быстрая блокировка экрана

### Автономность
- Wi-Fi выключается сам после 3 минут бездействия (настраивается)
- Часы на всех устройствах: NTP + программные часы без RTC, без расхода батареи
- Экран Автономность: время и страницы от последней зарядки
- Диагностический лог батареи для поиска ночного расхода

### Подсветка (X4 Pro)
- Двойное нажатие кнопки питания включает и выключает подсветку
- Панель подсветки: свайп вниз от верхнего края, яркость и теплота регулируются
  сразу, без перерисовок
- Запоминание яркости, теплоты и состояния при засыпании (отключается настройкой)

### Строка состояния и интерфейс
- Положение (верх/низ), полное скрытие, часы (слева/справа/по центру), номера
  страниц по главе или по книге, подменю настроек
- Игры: 2048, Сапёр, Шахматы
- Темы Classic / Lyra / Lyra3Covers / RoundedRaff / Minimal / Dashboard
- Режимы сенсора в читалке: тапы, свайпы, инвертированные тапы или полное
  отключение

### USB Drive (X4 Pro)
Ридер подключается к компьютеру как обычная флешка: SD-карта монтируется
напрямую, без Wi-Fi и веб-интерфейса.

## Установка

Прошивается как обычный CrossPoint: через web-флешер по USB
(https://crosspointreader.com/#flash-tools) или файлом с SD-карты.

Готовые сборки: раздел Releases, файл BookPoint_<версия>_x4pro.bin для X4 Pro.

### Залоченная X4 Pro (китайская версия)

На залоченных Pro установка CrossPoint-совместимой прошивки идёт в два шага.
Сначала разблокировка через официальный инструмент:

1. Скачайте Xteink Unlocker для X4 Pro со страницы
   https://crosspointreader.com/unlock
2. Запустите его и следуйте инструкции: устройство поднимает точку доступа
   Wi-Fi с именем `crosspoint`, пароль `11111111`. Подключение к ней иногда
   получается не с первой и даже не с пятой попытки, повторяйте.
3. После разблокировки ставьте BookPoint как обычно: файл `update.bin` на SD-карте
   с обновлением через меню прошивки, или web-флешер по USB.

Типичные проблемы: браузер не видит устройство в web-флешере до разблокировки
(это нормально для залоченных Pro), антивирус ругается на Unlocker (добавьте в
исключения). Если OTA-обновление не находится, воспользуйтесь обновлением с
SD-карты.

Не обновляйтесь через встроенный пункт «Проверить обновления»: он ставит
оригинальный CrossPoint.

## Сборка

git clone --recurse-submodules https://github.com/klanva/BookPoint.git
cd BookPoint
build.bat    # Windows; основная цель теперь env x4pro (ESP32-S3)

Результат: .pio/build/x4pro/firmware.bin.

## Дорожная карта

Приоритеты из код-аудита 18 прошивок (AUDIT_MAXIMAL.md, firmwares/*/AUDIT.md):
1. Light sleep race-to-sleep: простой 9.68 -> 2.78 мА (witchhunt)
2. Экраны сна со статистикой (Cover+Stats, Dashboard)
3. Flashcards SM-2 с CSV-колодами (vCodex, CrossPet)
4. Highlights с якорями, переживающими смену шрифта (vCodex)
5. Тепловая карта чтения + достижения + дневные цели (vCodex)
6. BuildArena + memory budget (witchhunt)
