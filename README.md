## О проекте

**BookPoint** — независимая открытая микропрограмма для флагманского ридера **Xteink X4 Pro**, спроектированная для надежного, быстрого и комфортного чтения.

В архитектуре прошивки реализован специализированный монохромный интерфейс, адаптированный под емкостный сенсор GT911 и аппаратные клавиши ридера Xteink X4 Pro. Графическая концепция ориентирована на эргономику ведущих аппаратных E-Ink платформ (Kobo OS, Kindle OS, PocketBook Linux).

## Ключевые особенности

### 1. Флагманский интерфейс (Modern E-Ink UI)
* **Эстетика свободного пространства:** строгая геометрия, 1px разделители, отсутствие лишнего шума и аляповатых рамок.
* **Умный статус-бар:** точные локальные часы по аппаратному RTC, русская дата, контурная батарейка с процентом и индикатором зарядки, уровень фронтальной подсветки, статус Wi-Fi.
* **Выпадающая шторка Центра управления (Quick Settings):** свайп от верхнего края экрана вызывает панель с независимыми плавными слайдерами подсветки (Холодный и Теплый свет), тумблерами Wi-Fi, темной темы, автоповорота и сна. На сенсорных устройствах наэкранные кнопки скрыты в пользу чистого жестового управления.
* **Доминантный блок «Сейчас читаю» (Hero Section):**
  - Полноразмерная обложка книги с эффектом книжного 3D-корешка (spine shadow).
  - Название книги, автор, капсульный индикатор прогресса со значением в процентах (`XX%`).
  - Оценка оставшегося времени до конца книги (`~XX мин`) и аккуратный счетчик серии дней чтения (`Серия: N дн.`).
  - Вся карточка является единой тач-зоной для мгновенного продолжения чтения.
* **Полка недавних книг (Recent Shelf):** горизонтальная полоса мини-обложек с прогрессом для открытия книги в одно касание.
* **Нижний док навигации:** лаконичные разделы (**Библиотека**, **Поиск**, **Статистика**, **Приложения**, **Настройки**) с векторными контурными иконками 32×32 и чистой типографикой без эмодзи.
* **Двойное управление (Touch + Buttons):**
  - Точные хит-боксы емкостного сенсора Goodix GT911 (≥44px) под геометрию экрана 800×480.
  - Аппаратное восстановление шины I2C и сенсора GT911 при сбоях для полного исключения зависаний.
  - Поддержка аппаратных кнопок и возврат клавишей Back.

### 2. Продвинутый движок чтения и типографики
* **Интерактивные оверлеи чтения:** вызов верхнего и нижнего меню тапом по центру экрана. Нижняя панель отображает интерактивный слайдер страниц, процент прочтения и расчетное время до конца текущей главы.
* **Плавающее меню типографики (Aa) на лету:** мгновенная настройка размера шрифта крупными кнопками (A- / A+), выбор гарнитур (включая JetBrains Mono, Roboto Condensed, OpenDyslexic), межстрочного интервала и ширины полей страницы с автосохранением и мгновенной переверсткой без выхода из книги.
* **Потоковый декодер Progressive JPEG (PJPEG):** аппаратное декодирование обложек и иллюстраций высокого разрешения через PSRAM без принудительного даунсэмплинга 1/8 и без нехватки памяти.
* **Сноски внизу страницы (Footnotes at bottom):** текст примечания отображается прямо под разделителем на текущей странице, как в настоящей бумажной книге — никаких раздражающих переходов в конец файла. Универсальный экстрактор поддерживает ЛитРес, royallib и внешние файлы сносок.
* **Поддерживаемые форматы:** EPUB 2/3, TXT, XTC / XTCH. Встроенные CSS-стили, гибкие переносы, поддержка CJK и RTL.
* **Автоматическое определение кодировок TXT:** встроенный частотный анализатор `TxtEncoding` автоматически определяет `Windows-1251`, `KOI8-R` и `CP866` в русскоязычных библиотеках и прозрачно конвертирует их в UTF-8 без «кракозябр».
* **Сенсорная русская клавиатура (ЙЦУКЕН / QWERTY):** нативная экранная клавиатура с тач-маршрутизацией и расширенными зонами касания для мгновенного поиска книг и ввода паролей Wi-Fi.

### 3. Галерея экранов спящего режима (Screensavers)
* **Культовая коллекция E-Ink заставок (480×800 и 800×480):**
  - 11 классических литературных тем Kindle и Kobo (печатные литеры, перьевые ручки, старинные гравюры, астрономические карты, карандаши, портреты Жюля Верна, Диккенса, Марка Твена, оригами и архитектура библиотек).
  - Аутентичные заставки из прошивок Onyx Boox, Moaan, Xiaomi Manga и iReader.
* **Гибкие режимы сна:** случайная ротация обложек при каждом уходе в сон, выбор конкретной заставки, режим обложки читаемой книги и отображение версии прошивки в светлой и темной теме.

### 4. Аппаратная архитектура и надежность X4 Pro (ESP32-S3)
* **Аппаратные часы реального времени (RTC BM8563):** физический чип Belling BM8563 (PCF8563-совместимый) по адресу `0x51` на шине `Wire` (SDA 39, SCL 38). Прямая аппаратная синхронизация `settimeofday()` на старте, обработка флага потери питания (VL bit) и полное отсутствие устаревших DS3231/0x68 зависимостей.
* **Защита аккумулятора CW2017 (<3.4V):** непрерывный контроль напряжения ячейки, автоматический сервисный экран «Батарея разряжена» и безопасный уход в глубокий сон при напряжении ниже 3400 мВ для предотвращения деградации аккумулятора.
* **Потокобезопасная шина I2C и сенсор GT911:** рекурсивный мьютекс FreeRTOS `ScopedI2CBusLock` между опросом тача GT911, часов BM8563 и батареи CW2017; 9-тактовый импульсный сброс SCL с формированием корректного аппаратного I2C STOP-условия при залипании SDA.
* **Буфер кадров и страниц в 8 МБ PSRAM:** графические фреймбуферы (800×480) и буферы страниц XTC (48–96 КБ) вынесены в PSRAM (`heap_caps_malloc`). Использование `std::nothrow` в графических конвертерах исключает аварийный сброс устройства при нехватке памяти.
* **Атомарная запись настроек:** сохранение параметров через временный файл исключает повреждение конфигурации при внезапной разрядке аккумулятора. Поддерживается системный псевдоним `BookPointSettings` с сохранением пути `/.crosspoint/` на microSD.
* **Двухканальная подсветка (Frontlight):**
  - Раздельное ШИМ-управление холодным и теплым каналами с логарифмической гамма-коррекцией.
  - Быстрое включение/выключение по **двойному нажатию кнопки питания**.
  - **Защита от утечки питания:** обесточивание шин подсветки во время сна (`Frontlight.park()`).
* **Энергосбережение:** интервальный Light Sleep снижает ток холостого хода до 2.8 мА; умный Wi-Fi с автоотключением через 3 минуты неактивности.
* **Аналитика чтения (StatsStore):** детальный учет времени чтения, скорости (страниц/час), сессий и экспорт в `reading_stats.csv`.

## Целевая аппаратная платформа

BookPoint OS разработана эксклюзивно для флагманского ридера **Xteink X4 Pro** и использует все аппаратные преимущества чипсета ESP32-S3:

| Подсистема / Компонент | Аппаратная спецификация | Назначение в BookPoint OS |
|---|---|---|
| **SoC / Процессор** | ESP32-S3 (Dual-Core Xtensa LX7 @ 240 МГц) | Высокая скорость рендеринга страниц, плавная анимация интерфейса |
| **Память** | 16 МБ Flash + 8 МБ Octal PSRAM | Фреймбуферы 800×480, буферы верстки EPUB и потоковое декодирование в PSRAM |
| **Дисплей** | 3.97" E-Ink 800×480 (SSD1677, 240 PPI) | Аппаратный 4-градационный рендеринг, быстрые волновые формы DU |
| **Сенсорный экран** | Емкостный контроллер Goodix GT911 | Управление жестами, шторка быстрых настроек, тап-зоны, экранная клавиатура |
| **Аппаратные часы (RTC)** | Belling BM8563 (I2C `0x51`, PCF8563-совместимый) | Надежный автономный ход часов при выключенном питании, быстрый старт |
| **Контроллер батареи** | CellWise CW2017 (I2C `0x63`) | Высокоточный OCV-мониторинг заряда и защита от глубокого разряда (<3.4V) |
| **Подсветка (Frontlight)** | Двухканальная CCT (Холодный GPIO8 / Теплый GPIO9) | Логарифмическая гамма-регулировка яркости и цветовой температуры |
| **Хранилище** | MicroSD слот (SDMMC 1-bit / SPI) | Локальная библиотека книг, шрифты, словари, кэш обложек |

## Установка и обновление

Прошивку можно установить через официальный USB Web-флешер или прямо с microSD-карты.

Готовые бинарники доступны в разделе [Releases](https://github.com/klanva/BookPoint/releases) (файл `BookPoint_2.2.2_x4pro.bin`).

### Официальные и разблокированные X4 Pro:
1. Скачайте `BookPoint_2.2.2_x4pro.bin`.
2. Подключите ридер к ПК по USB и откройте [Web-флешер CrossPoint](https://crosspointreader.com/#flash-tools).
3. Выберите файл прошивки и нажмите **Install**.
4. *Либо скопируйте файл на SD-карту с именем `update.bin` и запустите обновление через меню книги.*

### Залоченные X4 Pro (китайская версия):
1. Скачайте официальную утилиту **Xteink Unlocker** со страницы [crosspointreader.com/unlock](https://crosspointreader.com/unlock).
2. Запустите утилиту и следуйте инструкциям: ридер поднимет сервисную точку доступа Wi-Fi (`crosspoint` / пароль `11111111`).
3. После снятия китайской блокировки установите BookPoint через Web-флешер или SD-карту.

> [!TIP]
> Встроенный пункт «Проверить обновления» (OTA) перенастроен на официальный репозиторий BookPoint (`klanva/BookPoint`) и безопасно обновляет прошивку по Wi-Fi.

## Сборка из исходного кода

Проект собирается с помощью [PlatformIO](https://platformio.org/).

### Клонирование репозитория
```bash
git clone --recurse-submodules https://github.com/klanva/BookPoint.git
cd BookPoint
```

### Сборка прошивки
```bash
# Windows
build.bat

# Или через PlatformIO CLI
pio run -e x4pro
```

Готовый файл прошивки будет сформирован в `.pio/build/x4pro/firmware.bin`.

### Запуск E2E тестов
В проект встроен комплекс сквозных opaque-box тестов интерфейса, шрифтов, форматов и сенсора:
```bash
python tests/e2e/run_e2e_tests.py --all
```
*(230 тестов охватывают функциональное покрытие, интеграцию аппаратных шин, парсеры медиа, симуляцию BM8563, CW2017, GT911 и сенсорные жесты)*.
